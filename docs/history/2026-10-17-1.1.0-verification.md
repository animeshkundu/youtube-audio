   plus a sync test so the next format change fails the unit gate, not the browser lane.

   Mirrored; rows distinguish "alive but ciphered" (`audio+cipher`) from dead.
4. Local Firefox launch requires LaunchServices (`open -n -W`) GUI context plus a non-default
   Marionette port (a stray session holds 2828). Throwaway wrapper only; harness untouched.
