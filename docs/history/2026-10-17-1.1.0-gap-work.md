# Handoff: 1.1.0 gap work (reliability, fallbacks, music extras)

Date: 2026-10-17
Branch: `feat/1.1.0-gap-work` (branched from master `73a23b5`, version 1.1.0)

## Scope

The "gap and competitive" workstream on top of the merged 1.1.0 line: close the reliability gaps
that drive the AMO rating, widen the audio-source fallback chain, finish the music/download feature
surfaces, and cover each with tests and documentation. Every change is additive and fail-open.

## Changes

- **Audio-only fallback chain, Phase A + B (`src/shared/innertube.ts`).**
  - Phase A: added `IOS`, `ANDROID`, and `MWEB` personas to `MEDIA_CLIENTS` after VISIONOS and
    ANDROID_VR (order is the feature).
  - Phase B: added `TVHTML5_SIMPLY_EMBEDDED_PLAYER` as the last client. It serves age-restricted
    videos without a login but returns `signatureCipher` strings, so it is paired with a new pure
    `src/shared/cipher.ts` (base.js parse + reverse/splice/slice/swap replay) and a bounded,
    page-world, cached base.js fetcher (`entrypoints/main-world.ts`). A `signatureTimestamp` and the
    embed origin are added to that client's request body only.
  - `walkMediaClients` gained an optional `resolveCipheredUrl` hook and an `ok.resolvedAudioUrl`
    field; the download path prefers the decoded URL too.
- **Volume boost (`src/shared/audiograph.ts`, config, settings-diff, main-world, signals, options).**
  A limiter (`DynamicsCompressorNode`) is always in the chain and activates only above unity; the
  effective gain is `clamp(0.5, 2, loudnessGain * boostMultiplier)` with the multiplier clamped to
  `[1, 3]`. Off by default; a toggle plus amount slider in Music.
- **SponsorBlock categories (`src/shared/sponsorblock.ts`, options).** Expanded to all eleven
  categories; defaults stay sponsor + music_offtopic; the extra nine sit in a collapsed "All
  categories" disclosure.
- **Download metadata (`src/shared/download.ts`).** Filenames become "Author - Title"; a blank
  author is treated as absent.
- **Player resilience (`src/shared/player.ts`, `entrypoints/main-world.ts`, `content.ts`).**
  `loop` is preserved across the src swap and a new in-player loop button syncs it through the
  bridge; a `ratechange` listener keeps the snapshot's speed; Picture-in-Picture enter/leave is
  handled (never touching src); a bounded stall retry (max 2) and a hard media-`error` fail-open
  path both release to native playback.
- **Logger schema fixes (`src/shared/logger.ts`).** Added `audio.graph.boost`,
  `page.media-error`/`page.stall-*` where-values, and `stall-*`/`media-error` playback reasons. The
  earlier commits logged keys absent from the closed schema, which silently dropped those events;
  these are now captured.
- **Docs.** SPEC-022..030, ADR-0016 (Chrome port evaluation), ADR-0017 (permission model),
  Research 21 (live audio-only spike), and the release-note lines in `docs/release-notes/NEXT.md`.

## Testing

- Unit: new `cipher.test.ts` (parse/replay/fail-open), plus `cipher-fixture-sync.test.mjs`
  locking the bench fixture's base.js to the decoder; expanded `innertube.test.ts` (six-client
  order, cipher resolution, throwing/absent resolver, audio-only-off), `audiograph.test.ts`
  (limiter insert/activate, compressor-absent degradation, boost clamping), `download.test.ts`
  (author naming), `sponsorblock.test.ts` (eleven categories), `config-reset.test.ts` (boost
  clamp/normalize), `player.test.ts` (loop preservation, `setLoop`, ratechange adoption),
  `in-player-mount.test.ts` (loop button mount/order/removal), `logger.test.ts` (new vocabulary).
- Bench: `run-matrix.mjs` gained `volumeBoostEnabled` as a covering-array toggle plus two explicit
  boost combos, and `checkAudioGraph` is now boost-aware. `run-bench.mjs` snapshot adds
  `videoPlaybackRate`/`videoLoop`/loop-button fields; the toggle-off reclaim probe now sets and
  asserts a 1.5x rate; new `m8:signature-cipher-is-decoded-and-hijacked` and
  `m8:members-only-fails-open-to-native` cases drive the `CIPHER*`/`MEMBERS*` fixture modes.
- `npm run validate` green locally (typecheck, lint, format, 473 unit tests, MV2 + MV3 builds,
  `web-ext lint`). Bench + matrix run in CI.

## Safety

- Fail-open at every step: a missing base.js, an unrecognised bundle, a failed cipher decode, a
  stalled or errored hijack, and a PiP quirk all release to native playback. Every new network
  path is credentialless (`credentials: "omit"`) and same-origin (the page's own `ytcfg` /
  player script), so no new host permission and no new egress origin.
- The `PlayerHandle` sole-`<video>.src`-writer invariant is intact; the loop button and PiP handlers
  never touch src.
- No consent-flow change; no new optional permission.

## Follow-ups

- Live audio-only remains a documented spike (Research 21): not shipped.
- Per-site optional hosts remain designed but not shipped (ADR-0017).
- The hermetic bench could not be launched in the authoring sandbox; CI is the bench/matrix proof

- Version reconciliation: master merged as 1.1.0, so the earlier plan step that re-versioned this
  work to a 1.0.6 patch release is stale and was not performed.
